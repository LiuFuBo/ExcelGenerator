========================================
  漂流瓶 使用说明
========================================

【软件简介】

本软件包含三大功能模块：
  📊 Excel订单生成器 — 自动生成POS订单数据
  💧 批量水印 — 批量为图片添加门店水印信息
  📦 图片压缩 — 批量压缩图片体积

左侧导航栏点击对应图标即可切换功能页面。

========================================
一、Excel订单生成器
========================================

【功能说明】
自动生成随机销售日期和订单编号，并写入Excel文件。

【操作步骤】
1. 填写Excel文件名（无需输入.xlsx后缀，软件自动添加）
2. 选择"新建文件"或"追加文件"：
   - 新建文件：在桌面创建新的Excel文件
   - 追加文件：选择已有Excel文件，在末尾追加数据
3. 输入订单数量（1~9999）
4. 点击"▶ 开始生成"

【注意事项】
- 新建文件保存在桌面，文件名自动添加.xlsx后缀
- 追加文件时会自动识别或创建所需列（日期、订单号等）
- 日期范围：当月1日至今天，时间范围9:00~21:00
- 订单号格式：S + YYMMDD + 14位随机数字

========================================
二、批量水印
========================================

【功能说明】
批量为图片添加门店水印信息（城市、地址、日期、时间等），
输出带水印的图片到桌面"水印相册"文件夹。

【操作步骤】
1. 点击"选择图片"，从弹框中勾选需要的图片，点击"添加"
2. 在城市列表中勾选需要水印的城市
3. 填写年份和月份
4. 点击"▶ 开始添加水印"

【水印说明】
- 每张图片会分配一个门店地址（按勾选城市轮询分配）
- 水印内容包含：城市名称、门店地址、日期、时间、拍摄设备信息
- 输出目录：桌面/水印相册/

【注意事项】
- 图片数量不能超过勾选城市的门店总数，否则会提示"门店数量不足"
- 可通过增加勾选城市来解决门店不足的问题
- 图片选择弹框中可使用"全选"和"取消全选"快速操作
- 图片加载完成后才可进行水印操作（关注"已加载"提示状态）

========================================
三、图片压缩
========================================

【功能说明】
批量压缩图片体积，支持无损压缩和有损压缩两种模式，
输出压缩后的图片到桌面"已压缩图片"文件夹。

【操作步骤】
1. 点击"选择图片"，从弹框中勾选需要的图片，点击"添加"
2. 选择压缩方式：
   - 无损压缩：保持原格式，最高质量参数重编码优化，预估压缩10~30%体积
   - 有损压缩：降低画质换取更小体积，预估压缩40~60%体积
3. 查看压缩预估（原始大小、压缩后预估大小、压缩率）
4. 点击"▶ 开始压缩"

【压缩方式详细说明】

无损压缩（保持原格式，质量最优）：
- JPEG → JPEG（quality=85, optimize, progressive）
- PNG → PNG（compress_level=9, optimize）
- WebP → WebP（lossless, method=6）
- 其他格式 → PNG

有损压缩（体积最小，肉眼几乎无差异）：
- JPEG → JPEG（quality=75, optimize, progressive）
- PNG → JPEG（quality=75, 注意：PNG会转为JPEG格式，文件名变为.jpg）
- WebP → WebP（quality=75）
- 其他格式 → JPEG

【注意事项】
- PNG有损压缩会转为JPEG格式，透明通道会丢失
- 压缩预估为粗略计算，实际结果可能略有偏差
- 图片加载完成后才可进行压缩操作（关注"已加载"提示状态）
- 输出目录：桌面/已压缩图片/
- 若源图片来自"已压缩图片"文件夹，输出到"已压缩图片-新"避免覆盖

========================================
【通用说明】
========================================

- 图片选择弹框支持"全选"和"取消全选"快捷操作
- 已加载状态：橙色=正在加载，蓝色=加载完成
- 图片右上角红色圆形按钮可删除单张图片
- 压缩/水印完成后会自动清空图片列表，需重新选择
- 所有输出文件均保存在桌面对应文件夹中
